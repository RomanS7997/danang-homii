# Структура Danang Homii v1

Все перечисленные страницы доступны с префиксами `/ru`, `/en` и `/vi`.

| Маршрут после языка | Страница | Основной сценарий |
| --- | --- | --- |
| `/` | Главная | Фото и карта → квартира → просмотр |
| `/apartments` | Каталог | Поиск, район, спальни, максимальная цена, сортировка, избранное |
| `/apartments/seaside` | Квартира у моря | Характеристики, карта, сохранение, просмотр |
| `/apartments/studio` | Студия | Те же действия для выбранного объекта |
| `/apartments/river` | Квартира у реки | Те же действия для выбранного объекта |
| `/apartments/family` | Семейная квартира | Те же действия для выбранного объекта |
| `/districts` | Районы | Выбор района → отфильтрованный каталог или индивидуальный запрос |
| `/how-to-rent` | Как снять | Четыре шага, комиссия, FAQ, подбор |
| `/guides` | Полезное | Три практических материала |
| `/guides/choose-your-neighbourhood` | Выбор района | Оглавление и четыре раздела |
| `/guides/viewing-checklist` | Просмотр квартиры | Свет, техника, работа дома, вопросы |
| `/guides/moving-in` | Заселение | Осмотр, контакты, правила дома, первые привычки |
| `/about` | О нас | Подход, принципы, блок связи, переход для собственников |
| `/owners` | Собственникам | Знакомство с объектом → форма → локальное завершение |

Неизвестный маршрут показывает страницу 404 со ссылкой на каталог. Прямые ссылки и обновление страницы работают через SPA fallback. Дата заезда в подборе необязательна. В просмотре требуется только контакт. В форме собственника требуются район и контакт.

Параметры каталога: `area`, `beds`, `budget`, `q`, `saved`, `sort`. Они не переносятся на другие разделы, но остаются в истории каталога и сохраняются при смене языка. Параметры оформления: `variant`, `style`, `preview`.

## Источники и границы

- [Старый сайт](https://www.dananghomesliving.com/en): ориентир структуры аренды, информации о команде и сопровождении.
- [Раздел материалов](https://www.dananghomesliving.com/en/news): ориентир тем о районах и просмотре. Три коротких практических материала написаны для новой версии; авторы и даты старых публикаций не присваивались.
- Визуальный источник — уже выбранная и доработанная главная Homii; новые страницы продолжают её шрифты, цвета и сгенерированные изображения.
- Все четыре объекта остаются примерами. Реальные фотографии, цены, договорные условия, доступность, подтверждённые контакты и обработку заявок нужно подключить перед публичным запуском. Страница покупки не добавлялась: эта версия посвящена аренде.
- Это готовая для локального просмотра первая версия frontend, без административной панели и backend отправки заявок.

## Проверка

`npm run build`, `npm run test:i18n`, `npm run test:sites` прошли. В браузере проверены основные переходы, локальные формы, 27 сочетаний маршрутов/языков на ширине 320 px, страницы при 768/1024 px и главный экран на ноутбуке. Найденное переполнение формы собственника исправлено и перепроверено. Скриншоты и подробности — в `design-qa.md`.
