# Правила работы с Danang Homii

## Разработка и публикация

- Основной код находится в `src/`. Устанавливайте зависимости через `npm ci`.
- Запускайте локальный сервер для проверки; тестируйте desktop и настоящую ширину телефона.
- На GitHub Pages проект живёт под `/danang-homii/`. Используйте `assetPath`, `sitePath` и `appPath` из `src/paths.js`; не добавляйте абсолютные `/assets/...` строки в JS/JSX. CSS/HTML обрабатывает Vite.
- При добавлении страниц обновляйте `scripts/prepare-pages-build.mjs` и тест количества маршрутов.
- Сохраняйте `.openai/hosting.json`, `worker/index.js`, `scripts/prepare-sites-build.mjs` и `tests/sites-worker.test.mjs` для совместимости с исходной root/Sites-сборкой.
- Полная проверка: `npm run build`, `npm run test:i18n`, `npm run test:sites`, `npm run build:pages`, `npm run test:pages`.
- Для интерактивных гидов также запускайте `npm run test:explore`. Контент и переводы — `src/enrichment-content.js`, компоненты — `src/ExploreTools.jsx`.
- Push в `main` публикует сайт. Pull request проходит проверки без публикации. Не коммитьте секреты и `.env`.

## Согласованный дизайн

- Основной вариант 2: большое открытое фото и карта, раскрывающаяся рядом. Вариант 3 сохранён для сравнения.
- Сохраняйте тёплый ivory/navy, синие и шампань-градиенты, стеклянные растровые иллюстрации.
- Типографика: системный SF на Apple, локальный Inter Variable на остальных устройствах. Файлы Apple не распространяйте. После запроса на баланс: основной текст 16–17 px, кнопки 14–16 px, поля ввода 16 px, подписи 14–15 px. Заголовки разделов 28–42 px, карточек 18 px; не увеличивайте все элементы одинаково. Допустимые исключения — короткие надзаголовки 12 px и атрибуция карты 11 px. Уточнения находятся в `src/typography.css`.
- Логотип — прозрачный градиентный знак «дом и волна». Не возвращайте старый квадратный знак.
- Используйте утверждённые изображения; сгенерированные интерьеры и районы иллюстративны.
- У внутренних страниц своя серия из девяти сцен в `public/assets/editorial/`; не возвращайте повсеместное повторение иллюстраций главной. PNG и точные промпты хранятся в `design-assets/editorial/`, вне сборки.
- Панель сравнения видна только с `preview=1`.
- На телефоне кнопка квартиры находится сразу после фото и до карты. Общий подбор доступен в мобильном меню.

## Карта и взаимодействия

- Сохраняйте атрибуцию. Градиентная тема использует OpenFreeMap/MapLibre с OSM fallback, спокойная тема — OSM.
- Фото и карта связаны одной выбранной квартирой. На коротких картах цены могут быть вынесены с линиями к координатам.
- Вступление заметное и однократное: полное фото, раскрытие карты, каскад цен, короткое кольцо у выбранной цены.
- Цены ждут готовности подложки, раскрытия панели и входа карты в видимую область. Выбор квартиры не должен повторять каскад или терять клавиатурный фокус.
- Ручной выбор «Фото» отменяет отложенное автооткрытие. Поддерживайте повтор и reduced-motion.

## Данные и языки

- Все страницы и состояния переведены RU/EN/VI. Русские строки служат ключами словаря; используйте `t()`.
- Язык URL приоритетнее сохранённого; первый визит по умолчанию RU. Переключение сохраняет маршрут, фильтры, выбор и ввод форм.
- Избранное хранится локально; фильтры — в URL. Поиск поддерживает три языка и вьетнамские слова без диакритики.
- Формы — локальное демо. Не показывайте фиктивную отправку/бронь. Просмотр требует контакт, время необязательно. Подбор требует бюджет и контакт, дата необязательна.
- Цены, координаты и доступность примеров не live-данные. Не переносите непроверенные контакты и условия старого сайта.
- Backend, реальные условия и расширенная галерея пока не реализованы. Описывайте ограничения точно.
